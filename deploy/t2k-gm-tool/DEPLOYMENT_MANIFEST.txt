## Deployment Steps

1. Extract files to target directory
2. Run INSTALL_SERVER.bat (one-time)
3. Double-click run.cmd to start server
4. Open http://localhost:3000 in browser
5. Log in with admin/admin
6. Change password immediately
7. Begin creating campaigns

## System Requirements

- Windows 10+ or macOS 10.15+
- Node.js 24.0.0 or later
- 4 GB RAM (8 GB recommended)
- 2 GB free disk space
- Modern web browser (Chrome, Edge, Firefox, Safari)

## Upgrading

To upgrade to a new version:
1. Backup your data/ folder
2. Extract new version files (overwrite .cjs and .html files)
3. Run INSTALL_SERVER.bat again
4. Copy data/ back from backup
5. Start server as normal

Data is never overwritten during upgrade.

## Troubleshooting Deployment

### Installation fails
- Check Node.js version: `node --version` (must be 24+)
- Run as Administrator
- Check internet connection for npm install

### Server won't start
- Port 3000 may be in use
- Windows Firewall may block Node.js
- Check server console for error messages

### Browser can't connect
- Verify server is running (check console output)
- Use http://localhost:3000 (not https)
- Check Windows Firewall allows Node.js

### Database errors
- Delete data/campaigns.db to reset database
- Keep regular backups of data/ folder
- Check disk space (minimum 2 GB free)
