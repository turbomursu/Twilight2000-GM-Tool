## Player Character Creation – Life Path System

### Step-by-Step Life Path Process

#### 1. Start (Age 18)
- **Starting Attributes**: All at C rating (D8)
- **Starting CUF**: D rating
- Character begins as 18-year-old

#### 2. Attribute Generation
Roll 2D6 for attribute points to distribute:
- 1-2: 1 point
- 3-4: 2 points
- 5-6: 3 points
- **Total**: 2-6 points distributed

Rules:
- Can drop one attribute C→D for +1 extra point
- No attribute above A rating
- All attributes start at C (D8)

#### 3. Choose Nationality
- Americans are typical but any nation affected by WWIII is valid
- Affects starting gear and context

#### 4. Childhood (Roll 1D6)
- Determines background and early life experience
- Provides 1 skill and 1 specialty from childhood table (reference pg. 32 of original)
- "Much like in real life, there are ample opportunities to flesh out your character's life and motivations"

#### 5. Career Terms (Multiple possible, typically 4-year terms)

**For each career term:**
1. Choose military or civilian career
   - Must meet listed attribute requirements
   - If military: note starting rank and gear for Combat Arms
2. Gain 2 skills by 2 ratings (or 1 skill by 2 ratings if promotion achieved)
   - If new skill: starts at C (D8)
   - Can use: Stamina, Mobility, Driving, Ranged Combat, or any career skill
   - Draft rule: if civilian non-local character and war breaks out, must choose Ranged Combat
3. Roll for Promotion (1D6 unmodified)
   - Success: promoted, roll specialty, increase CUF if military/intelligence
   - Specialty: if you already have it, reroll
4. Determine aging effects
   - Roll 1D8 to determine years aged in this term
   - Add result to character age
   - Roll 1D8 to see if aging has effects (if effect, can reduce one attribute at GM choice)
5. War breaks out? (Roll 1D8)
   - If roll ≤ number of completed terms, war breaks out
   - Cannot roll under 1 (minimum always 1)
   - Cannot roll over number of terms completed initially
   - **First term**: War breaks out automatically after first term

**The Draft** (applies if final civilian term and not native):
- Character is drafted into military
- One of two skill choices must be Ranged Combat (unless already D+)
- Must roll specialty in "Military" column
- Get starting gear from Combat Arms career choice

#### 6. Finalize Character
- **Appearance**: Clothing, mannerisms, details
- **Name & Handle**: Name for general use; handle for radio communications
- **Big Dream**: Core motivation/aspiration
  - Acting in alignment: +1 modifier to skill rolls
  - Reflects character's core motivation in the world
- **Buddy**: Personal attachment to one other character
  - Making sacrifice for buddy: +1 modifier to skill roll
  - Watching buddy injured: causes mental stress (CUF roll)
- **Moral Code**: Statement capturing character's morals/values
  - Acting within code: +1 modifier to skill rolls
  - Betraying code: immediately take 1 stress damage, but can choose new code after session
  - Acting in alignment: can net XP rewards
- **Starting Gear**: Pick gear per final career term choice
- **Rations**: Get D6 each of food, water, and ammunition (usable as currency)
- **Vehicle** (optional): Group may roll for starting vehicle if allowed

## Attributes (Rated A–D)

| Rating | Dice | Description |
|--------|------|-------------|
| A | D12 | Peak human condition |
| B | D10 | Above average, capable |
| C | D8  | Average |
| D | D6  | Feeble or below average |

### The Four Attributes

- **Strength (STR)**: Muscle power, toughness, physical endurance
- **Agility (AGI)**: Body control, speed, fine motor skills
- **Intelligence (INT)**: Perception, intellect, mental stability
- **Empathy (EMP)**: Charisma, amiability, emotional stability

## Skills (Rated A–F)

| Rating | Dice | Description |
|--------|------|-------------|
| A | D12 | Peak human condition |
| B | D10 | Above average, capable |
| C | D8  | Average |
| D | D6  | Feeble or below average |
| F | — | Untrained (roll only related attribute die) |

### Skill Descriptions

| Skill | Description |
|-------|-------------|
| **Close Combat** | Melee weapons and unarmed fighting |
| **Heavy Weapons** | Machine guns, rocket launchers, ATGMs, vehicle cannons, mortars, howitzers |
| **Stamina** | Toughness and endurance |
| **Driving** | Advanced wheeled/tracked vehicle techniques; some specialties for specific vehicle types |
| **Mobility** | Running, jumping, climbing |
| **Ranged Combat** | Pistols, rifles, shotguns, bows, crossbows (not machine guns) |
| **Recon** | Spotting enemies, stealth, performing and avoiding ambushes |
| **Survival** | Finding food and shelter in the wild |
| **Tech** | Repair damaged equipment, scrounge vital parts, crafting |
| **Command** | Rally teammates, effects unit morale |
| **Medical Aid** | Treat injuries on self and others |
| **Persuasion** | Negotiation, getting others to cooperate; affected by bargaining position and rank |

### Specialties

- Represent additional expertise in a narrow part of a skill
- Give additional positive modifiers to skill rolls
- Gained through career, promotion, childhood, or term selection
- If rolled specialty already held, reroll for a different one

## Coolness Under Fire (CUF)

**Definition**: Represents how calm and collected your character remains during stressful situations (like combat). Graded A–D like attributes.

**During gameplay**: When particularly intense moments occur (like getting shot at), roll dice corresponding to CUF rating.

**Advancement**:
- During any session where you successfully roll your CUF, roll your CUF base die
- On result of 1: CUF increases one step (maximum A)
- When CUF increases: roll EMP base die; on success, Empathy reduces one step

---

## Unit Morale

**Definition**: Party/unit has morale rating A–D (controlled by events involving entire party).

**Calculation**:
- Typically equals highest Command skill score of any character in unit
- Unit morale can be added to individual CUF rolls during stress situations

**After each session**: Unit morale may change based on session events (consult pg. 41 of original).

## Capacity & Carrying

**Encumbrance System**: Measured in units; each unit weighs roughly 3 kg.

**Carrying Capacity**: 
- Character's Strength dice size determines units they can carry without being slowed
- Example: STR D10 can carry 10 units

**Carrying Penalties**: Apply when exceeding capacity (specific rule procedure and item data remain verified from authoritative source).

## Skill Rolls

### Basic Skill Roll Procedure

1. Grab two dice:
   - One die = attribute rating (A–D, sized D12–D6)
   - One die = skill rating (A–F, sized D12–D6 or untrained)

2. Roll both dice

3. **Success**: Roll 6 or higher on either die
   - 6–9: 1 success
   - 10+: 2 successes
   - Maximum possible: 4 successes (both dice roll 10+)

4. **Failure**: Both dice roll under 6
   - Referee determines consequences
   - Character may "Push" a roll (described p. 45 of original)

### Modifiers

- **Positive Modifier**: Increase die size by one step
- **Negative Modifier**: Decrease die size by one step
- Modifiers can stack

### Opposed Rolls

- Used when characters compete (e.g., combat, contests)
- Each character rolls relevant skill/attribute combination
- Character with more successes "wins"
- May use different skills for different characters

### Group Rolls & Helping

- One character handles primary task (Group Roll character)
- Others can "Help" to add positive modifiers to their roll
- Helping others uses the slowest action available

## Character Development After Creation

### Experience Points
- Earned during gameplay
- Spent to improve character
- See pg. 40 for details

### CUF Advancement
- See "Coolness Under Fire" section above

### Group Morale Changes
- After each session, unit morale may change per session events
- Consult pg. 41 for morale adjustment procedures

### Other Changes
- After each session, may choose new moral code if current one was betrayed during session
- May choose new "Big Dream"
- May choose new "Buddy" (one change at a time)

## NPC Creation

The Referee's Manual includes a **Typical NPCs** reference table (p. 37) with ready-to-use profiles. Each profile provides attributes, Hit Capacity, CUF, skills, and typical gear. Use those source profiles when preparing a matching NPC rather than treating the Life Path aid as the only NPC reference.

The page 37 table is a reference, not an automated creation procedure. Keep its listed values and equipment as source data; any changes or details not covered by the table are GM-defined. Do not infer derived rules effects from the profiles unless verified separately.

For NPCs not covered by a reference profile, the GM may assign attributes and skills to suit the NPC's role. Mark such choices as GM-defined and keep any unverified rules effects under GM adjudication.
