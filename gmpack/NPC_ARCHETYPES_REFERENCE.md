### How to Use This Reference

The image from Referee's Manual page 37 shows typical NPC character profiles ready for quick use in campaigns. These serve as templates for:

- Quick NPC generation without rolling lifepath
- Consistent archetypes for common roles (soldiers, civilians, specialists)
- Attribute/skill/CUF starting points for various character types
- Equipment loadouts by profession/rank
