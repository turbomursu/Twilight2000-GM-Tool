Installation Time

Quick Start

Prerequisites

  • Windows 10+, macOS 10.15+, or Linux
  • Node.js 24+ from nodejs.org
  • 4 GB RAM (8 GB recommended)
  • 2 GB free disk space

Installation (3 Steps)

  1. Run installer:
    INSTALL_SERVER.bat
  2. Start server:
    npm start
  3. Open browser:
    http://localhost:3000

Default login: admin / admin (change immediately!)
